`docs/screenshots/editor-before-actual.png`

## V3 Insert

`docs/screenshots/editor-v3-insert-actual.png`

24개 primitive가 카테고리형 카드로 표시되는 실제 렌더다. 이 카드는 클릭과 drag payload를 모두 제공한다.

## Compact

`docs/screenshots/editor-v3-1366-actual.png`

1366×768 실제 Chromium 렌더다. 중앙 artboard는 캔버스 내부 스크롤을 사용하며 문서 자체 overflow는 없다.
