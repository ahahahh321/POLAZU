# POLAZU Editor rebuild — 먼저 읽기

이 전달본은 사용자가 업로드한 `interface-lab.zip`을 다시 분석해 실제로 수정한 **프로젝트·UI 에디터 작업 소스**입니다. 이전에 존재하지 않았던 ZIP을 복원한 바이트 동일본이 아닙니다. 업로드 원본은 변경하지 않았습니다.

- 시작: `LOCAL_MIGRATION.md`
- 구현 명세·제약: `FEATURES.md`, `SUPPORT_MATRIX.md`
- 실제 실행 결과: `TEST_REPORT.md`, 배포 ZIP의 `verification/`
- 설계·파일 연결: `ARCHITECTURE.md`
- 원본 대비 수정/추가 파일: 전달 ZIP의 `changes.json`
- 브라우저 동작 확인 예: `verification/browser/*.png` (이미지 생성이 아니라 실제 컴포넌트 실행 캡처)

## 정확한 상태

React/Next.js 중심 에디터·소스 패치·흐름도·화면 상태·연결 에이전트·공유 서버 코드가 포함됩니다. **488개 후보 전부를 구현했다거나, 모든 요청의 모든 예외를 검증한 운영 완성본이라는 뜻은 아닙니다.** 구현된 기능, 조건부 동작, 미구현 기능과 실행하지 못한 검사는 명세에서 구분합니다.

이 환경에는 Linux용 Next 네이티브 의존성과 Gradle 배포본/의존성이 없고 다운로드 DNS 접근이 실패했습니다. 실제 브라우저 네트워크 탐색은 관리 정책으로 차단되었습니다. 이 제한을 우회하지 않았으며, 브라우저 DOM 검사는 명시적 테스트 어댑터로 수행했습니다. 따라서 로컬에서 정식 빌드·Spring/MySQL·실제 GitHub·브라우저 보안 정책을 확인하기 전 운영 반영하지 마세요.

## 제외물

`.env`, `.git`, `node_modules`, `.next`, `out`, 빌드 결과, 기존 중첩 배포 ZIP, 폰트 바이너리는 전달 ZIP에 넣지 않습니다. 기존 폰트 파일은 로컬 프로젝트에서 유지하세요. 새 폴더에서는 시스템 폰트로 대체될 수 있습니다. 의존성은 대상 PC에서 `npm ci`로 설치하세요. 현재 작업 폴더에 다른 OS의 `node_modules`를 복사하지 마세요.
